# Stripy Horse Java SDK

Official Java client for the [Stripy Horse](https://stripyhorse.io) API - Zebra/ZPL
developer tools: render ZPL to PNG, convert PDFs/images/HTML to print-ready ZPL,
and drive hosted virtual Zebra printers from your tests.

Generated from the live [OpenAPI spec](https://stripyhorse.io/openapi.yaml), which is
itself emitted from the server's handler code, so the SDK can never drift from the API.

Java 8+, OkHttp/Gson based. Maven (`pom.xml`) and Gradle builds included.

## Setup

```java
import io.stripyhorse.ApiClient;
import io.stripyhorse.Configuration;
import io.stripyhorse.api.*;
import io.stripyhorse.model.*;

ApiClient client = Configuration.getDefaultApiClient();
client.setBearerToken("sh_live_YOUR_KEY");
```

## Render ZPL to PNG

```java
RenderApi render = new RenderApi(client);
RenderOutputBody out = render.renderZpl(new RenderInputBody()
    .zpl("^XA^FO50,50^A0N,45,45^FDHello^FS^XZ")
    .preset(RenderInputBody.PresetEnum._4X6));
byte[] png = Base64.getDecoder().decode(out.getLabels().get(0).getPng());
Files.write(Path.of("label.png"), png);
```

## Convert a PDF (or PNG/GIF/JPEG) to ZPL

```java
ConvertApi convert = new ConvertApi(client);
ConvertOutputBody result = convert.convertDocument(
    new File("shipping-label.pdf"),
    null, null, null, null, "4x6", null, null, null, null);
for (ConvertedPage page : result.getPages())
    sendToPrinter(page.getZpl());
```

## Design a label in HTML, get ZPL

```java
HtmlOutputBody out = convert.convertHtml(new HtmlInputBody()
    .html("<div style=\"position:absolute;left:40px;top:40px;font-size:50px\">Hello</div>")
    .preset(HtmlInputBody.PresetEnum._4X6));
System.out.println(out.getZpl());
```

## Test label printing in CI with a virtual printer

```java
SimulatorApi sim = new SimulatorApi(client);

PrinterBody printer = sim.createPrinter(new CreatePrinterInputBody()
    .name("ci-run-42").preset(CreatePrinterInputBody.PresetEnum._4X6));

// Point the system under test at the printer, exactly like hardware:
String addr = printer.getTcp().getHost() + ":" + printer.getTcp().getPort();

// ... run your fulfillment code against addr ...

// Then assert on what it printed:
ListJobsOutputBody jobs = sim.listJobs(printer.getId(), null, null);
assert jobs.getJobs().size() == 1;

// Reproduce a paper-out jam and watch jobs hold in the buffer:
sim.setPrinterFaults(printer.getId(), new Faults().paperOut(true));
```

## Errors

API errors throw `io.stripyhorse.ApiException`; `getResponseBody()` carries the
JSON error envelope. HTTP 429 includes a `Retry-After` header.

## Regenerating

This SDK is generated by `sdk/generate.sh java` in the
[main repo](https://github.com/Stripy-Horse/stripyhorse-io); hand edits will be overwritten.
